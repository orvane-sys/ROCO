# ROCO logo

| File | Use |
|---|---|
| `roco-logo-light.svg` | Mark and name, for light backgrounds |
| `roco-logo-dark.svg` | Mark and name, for dark backgrounds |
| `../../public/favicon.svg` | Simpler mark for 24 px and under |

`src/components/RocoLogo.tsx` holds the same drawing for the page. `npm run lint` checks that the files here match it.

## How it was made

The mark was first drafted with an AI image tool (OpenAI's ChatGPT image generation), then redrawn by hand as vector
paths. These files contain no generated pixels.
